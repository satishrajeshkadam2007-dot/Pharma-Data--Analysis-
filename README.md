# Pharma-Data--Analysis-
# Exploratory Data Analysis (EDA) on Pharmaceutical Drugs

## Project Overview
This project focuses on analyzing pharmaceutical datasets to understand drug compositions, chemical properties, and medical safety rules. It combines my background in **B.Sc. Chemistry** with **Data Science** concepts to extract valuable insights from molecular data.

## Core Concepts Covered
1. **Data Cleaning:** Handling missing chemical formulas and standardizing drug names.
2. **Feature Extraction:** Identifying molecular weight and functional groups using digital chemical descriptors.
3. **Data Visualization:** Plotting correlation graphs between chemical properties and drug side-effects.

## Tools & Libraries to be Used
* **Language:** Python
* **Data Libraries:** Pandas, NumPy
* **Chemistry Library:** RDKit
* **Visualization:** Matplotlib, Seaborn

## Expected Outcomes
* Identify patterns that cause drug side-effects.
* Speed up the virtual screening process for new drug molecules.
* Clean and format raw clinical trial data for faster analysis.
